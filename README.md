# Lumora Home — عرض سعر إدارة سوشال ميديا

موقع صفحة واحدة (HTML فقط) — بدون أي مكتبات أو تثبيت.

## النشر على GitHub Pages
1. ارفع الملفات (`index.html` و `.nojekyll` و `README.md`) على مستودع جديد.
2. من **Settings → Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
4. احفظ، وبعد دقيقة بيظهر الرابط: `https://USERNAME.github.io/REPO-NAME/`
